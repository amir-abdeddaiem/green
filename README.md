# 🌿 GreenScale: Sustainability Platform

A full-stack solution for businesses to track, analyze, and report their carbon footprint.

## 🚀 Features
- **Authentication:** Secure login/registration with bcrypt hashing.
- **Real-time Dashboard:** Track CO2, Electricity, and Gas usage.
- **Visual Analytics:** Interactive charts for emission trends.
- **Reporting:** Export data to CSV/PDF for compliance.

## 🛠️ Tech Stack
- **Frontend:** React, Tailwind CSS, Lucide Icons, Recharts.
- **Backend:** FastAPI (Python), SQLAlchemy ORM.
- **Database:** MySQL (XAMPP).

## 📥 Installation
1. Clone the repo: `git clone <repo-url>`
2. Setup Backend: `cd backend && pip install -r requirements.txt`
3. Setup Frontend: `cd frontend && npm install`
